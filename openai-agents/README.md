# OpenAI Agents SDK + x402check

Example: wrap [x402check](https://x402check.dev) tools for the OpenAI Agents SDK.

```bash
npm install @openai/agents x402check-client zod
```

See `agent.mjs`. Set `X402CHECK_URL=https://x402check.dev` and pay $0.01 USDC Exact per check on Base (1 free regular check per wallet).
